CHILD-SAFE VENDING / v1.0
CORE CONCEPT
핵심 컨셉 및 아이디어
초음파 센서 · Key Matrix · RFID · LCD · LED · 펌프 · 온도 센서를 활용해
사용자 접근 감지 → 음료 선택 → RFID 결제 → 음료 배출 →
고온 경고까지 수행하는 스마트 음료 자판기를 구현한다.
SAFETY FEATURE
컵 배출구 고온 감지 → LCD · RGB LED · 부저로 경고
각 음료별로 독립된 펌프와 호스를 구성하여 선택한 음료만 배출되며, 배출구 주변 온도가 일정 기준 이상이면 시각·청각 경고가 동시에 발생한다.
MOTIVATION
왜 만들게 되었는지
01 · PROBLEM
문제 인식
기존 자판기는 버튼을 누르고 결제하면 음료가 나오는 단순 구조. 접근 시 자동 작동, 결제 자동화, 안전 기능이 부족했다.
02 · MOTIVE
제작 동기
수업에서 배운 입출력 장치와 센서 제어를 종합적으로 적용하기 위해 초음파 · LCD · Key Matrix · RFID · LED · 온도 센서 · 부저 · 펌프를 한 시스템으로 묶었다.
03 · DIFFERENCE
차별점
온도 센서로 일정 온도 이상 시 경고음을 울리고 LED · LCD로 위험을 표시하여 어린이 안전 기능을 추가한 자판기로 차별화.

RFID PAYMENT NOTE
RFID 카드를 태그하면 실제 돈이 빠지는 구조가 아니라 코드 안에 카드별 잔액을 미리 설정하는 방식으로 구현한다.

HOW IT WORKS
핵심 구성 소자 작동 원리
01
초음파 센서
초음파의 송수신 시간 차이로 거리 측정
→ 사용자 접근 감지
02
LCD
전기 신호를 문자로 표시
→ 메뉴 · 가격 · 결제 상태 표시
03
버튼 (Key Matrix)
행과 열의 연결 상태로 입력 감지
→ 음료 선택 및 확인
04
RFID
무선 주파수로 카드 UID 인식
→ 카드 결제 및 잔액 확인
05
펌프
전동기로 액체에 압력 에너지 전달
→ 선택 음료 배출
06
온도 센서
온도를 전기 신호로 변환
→ 배출구 고온 감지
07
RGB LED
전류에 따라 색상 출력
→ 작동 상태 및 위험 표시
08
피에조 부저
전기 신호를 진동으로 바꿔 소리 발생
→ 고온 경고음 출력
09
모터 제어 모듈
작은 제어 신호로 큰 부하 제어
→ 펌프 ON/OFF 제어
CLOSING
단순히 음료를 파는 자판기를 넘어,
어린이의 안전까지 고려하는 자판기로.
센서 · 제어 · 결제 · 안전 — 네 개의 흐름이 하나의 시스템으로.
