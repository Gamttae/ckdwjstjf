자판기는 학교·공공장소 어디에나 있다. 보호자 없이 어린이가 직접 사용하는 빈도가 가장 높은 음료 기기다.
그래서 우리는 자판기 단계에서 고온 음료 배출 시 즉시 경고하고, 어린이가 무심코 손을 가져가지 못하도록 시각·청각 보호 장치가 작동하는 시스템을 만들어 보기로 했다.

CHILD-SAFE VENDING / v1.0
CORE CONCEPT
핵심 컨셉 및 아이디어
초음파 센서 · 버튼 · RFID · LCD · LED · 펌프 · 온도 센서를 활용해
사용자 접근 감지 → 음료 선택 → RFID 결제 → 음료 배출 →
고온 경고까지 수행하는 스마트 음료 자판기를 구현한다.
SAFETY FEATURE
컵 배출구 고온 감지 → LCD · RGB LED · 부저로 경고
각 음료별로 독립된 펌프와 호스를 구성하여 선택한 음료만 배출되며, 배출구 주변 온도가 일정 기준 이상이면 시각·청각 경고가 동시에 발생한다.
MOTIVATION
왜 만들게 되었는지
01 · PROBLEM
문제 인식
기존 자판기는 버튼을 누르고 결제하면 음료가 나오는 단순 구조. 접근 시 자동 작동, 결제 자동화, 안전 기능이 부족했다.
02 · MOTIVE
제작 동기
수업에서 배운 입출력 장치와 센서 제어를 종합적으로 적용하기 위해 초음파 · LCD · 버튼 · RFID · LED · 온도 센서 · 부저 · 펌프를 한 시스템으로 묶었다.
03 · DIFFERENCE
차별점
온도 센서로 일정 온도 이상 시 경고음을 울리고 LED · LCD로 위험을 표시하여 어린이 안전 기능을 추가한 자판기로 차별화.

사용자가 접근하면 자판기가 활성화되고, 음료 선택과 RFID 결제 과정을 거친 뒤 잔액이 충분할 경우 선택된 음료가 배출된다.
입력 시간 초과, 잔액 부족, 고온 감지와 같은 예외 상황이 발생하면 안내 문구를 출력한 뒤 초기 상태로 복귀한다.
RFID PAYMENT NOTE
RFID는 프로토타입용 가상 결제 방식으로 구현하며, 카드 UID별 잔액과 선택 음료의 가격을 비교해 결제 가능 여부를 판단한다.
